# Whales — мод для Minecraft 1.21.11 (Fabric)

## Что добавляет

**Кит** (`whales:whale`)
- Спавнится в глубоких океанах по 1–2, плавает медленно, смотрит на игрока, плывёт за ножницами в руке.
- Обрастает ракушками (от 0 до 4, видны на спине и голове). Новая ракушка отрастает в среднем раз в ~5 минут.
- ПКМ ножницами срезает одну ракушку и даёт 1–2 предмета «Ракушка». Работает и через раздатчик с ножницами.
- Когда срезана последняя ракушка, кит в благодарность выпрыгивает из воды и с брызгами разбрасывает вокруг 5–8 бросков улова по таблице лута рыбалки. Иногда к этому добавляются раковина наутилуса и кристаллы призмарина.
- На суше без воды и дождя через 30 секунд начинает пересыхать.

**Ракушка** (`whales:barnacle`) — ингредиент.

**Ракушечный шип** (`whales:barnacle_spike`) — редстоун-ловушка.
- Рецепт (выход 2 шт.):
  ```
  Р . Р
  Р Ж Р      Р — ракушка, Ж — железный слиток, К — редстоун
  Р К Р
  ```
- Без сигнала шип спрятан и блок безопасен. При подаче сигнала (нажимная плита, рычаг, растяжка) шип выдвигается и сразу наносит 3 сердца тому, кто стоит сверху, подбрасывая его. Пока сигнал держится, каждый стоящий на блоке получает урон.
- Добывается киркой. Для урона используется свой тип с сообщением о смерти.

**Китовый скелет** (whale fall) — генерируется на дне океанов, в среднем раз на 48 чанков океана.
- Состоит из черепа с глазницами и проломом сверху, нижней челюсти, позвоночника, 6 арок рёбер (уменьшаются к хвосту) и хвостового плавника. Всё из костных блоков, с частичным разрушением и травой вокруг.
- Внутри черепа спрятан сундук с лутом: ракушки, кости, призмарин, самородки, наутилус, изредка сердце моря.

## Как собрать .jar

Нужен **JDK 21** (например, Temurin 21).

1. Откройте папку `whales-mod` в терминале.
2. Windows: `gradlew.bat build`. Linux/macOS: `./gradlew build`.
   Первый запуск скачивает Gradle, Minecraft и маппинги, это займёт несколько минут.
3. Готовый мод будет в `build/libs/whales-1.0.0.jar`. Файл `-sources.jar` не нужен.
4. Положите jar в `.minecraft/mods` вместе с **Fabric API 0.141.x+1.21.11**. Нужен Fabric Loader 0.20.1 или новее.

Тест без установки: `gradlew.bat runClient`.

## Проверка в игре

```
/summon whales:whale ~ ~ ~
/place feature whales:whale_fall
```
Для `/place` нужно стоять на дне в воде, минимум 6 блоков воды над головой.

## Структура

- `src/main/java/.../entity/WhaleEntity.java` — поведение кита, ракушки, благодарность.
- `src/main/java/.../block/BarnacleSpikeBlock.java` — шип-ловушка.
- `src/main/java/.../worldgen/WhaleFallFeature.java` — генерация скелета.
- `src/client/java/.../client/` — модель, рендер и анимация кита (текстура 256x64).
- `src/main/resources/data/whales/` — рецепт, лут сундука, тип урона, размещение скелета.

Версии: Minecraft 1.21.11, Loom 1.19, Fabric API 0.141.6+1.21.11, Mojang mappings, Java 21.
